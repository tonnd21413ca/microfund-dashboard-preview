# SME Intelligence Dashboard

**Micro Fund JSC**

An interactive analytics dashboard covering more than 1.05 million Vietnamese enterprises, providing geographic, financial, credit, and business-level insights.

> **Note:** This repository is intended as a visual preview only. The production source code is proprietary and is therefore not included.
>
> The live interactive dashboard is available via the [Micro Fund](https://www.microfund.vn/) website. Access is free after registering with a company email address.
